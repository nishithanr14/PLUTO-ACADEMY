# Project 01: World Happiness Report Data Analysis

## Project Overview

This project analyzes the World Happiness Report dataset using Python, Pandas, Matplotlib, and Seaborn. The goal is to understand the factors that influence happiness across different countries, identify patterns and trends, visualize key findings, and provide data-driven insights.

## Objectives

* Load and inspect the dataset.
* Clean and preprocess the data.
* Perform Exploratory Data Analysis (EDA).
* Create meaningful visualizations.
* Extract insights and recommendations based on the analysis.

## Dataset

Dataset: World Happiness Report

Source: Kaggle (unsdsn/world-happiness)

The dataset contains information about happiness scores and factors contributing to happiness, including:

* GDP per capita
* Social support
* Healthy life expectancy
* Freedom to make life choices
* Generosity
* Perceptions of corruption

## Project Workflow

### Step 1: Data Loading and Inspection

* Loaded the dataset using Pandas.
* Examined dataset shape and structure.
* Checked data types.
* Identified missing values.
* Checked for duplicate records.

### Step 2: Data Cleaning

* Removed duplicate records.
* Inspected missing values.
* Verified data types.
* Retained relevant features for analysis.

### Step 3: Exploratory Data Analysis

The following questions were answered:

1. Which country has the highest happiness score?
2. Which country has the lowest happiness score?
3. What are the top 10 happiest countries?
4. What is the overall distribution of happiness scores?
5. Which factors are most strongly correlated with happiness?

### Step 4: Visualizations

The project includes the following visualizations:

1. Bar Chart – Top 10 Happiest Countries
2. Line Chart – Happiness Scores of Top Countries
3. Histogram – Distribution of Happiness Scores
4. Scatter Plot – GDP per Capita vs Happiness Score
5. Pie Chart – Top 5 Happiest Countries
6. Heatmap – Correlation Matrix

### Step 5: Key Insights

1. Countries with higher GDP per capita generally have higher happiness scores.
2. Social support is strongly associated with happiness.
3. Healthy life expectancy positively impacts overall happiness.
4. Most countries fall within a moderate happiness range.
5. Multiple factors together contribute to happiness rather than a single factor alone.

## Surprising Finding

One interesting observation was that GDP alone does not fully explain happiness levels. Several countries with similar economic performance showed noticeably different happiness scores, indicating that social support, freedom, and health also play significant roles.
